# Скриншоти для звіту

У репозиторії вже є **ілюстративні** PNG (`health-200.png`, `health-503.png`, `shutdown.png`), щоб у кореневому `README.md` були прев’ю. Якщо викладач вимагає саме **реальні** знімки з вашого ПК — перезапишіть ці файли своїми скриншотами (збережіть ті самі імена).

Вимоги до змісту:

| Файл | Зміст |
|------|--------|
| `health-200.png` | `curl -i localhost:8080/health` → **HTTP/1.1 200**, БД запущена |
| `health-503.png` | Той самий запит → **HTTP/1.1 503**, БД зупинена вручну |
| `shutdown.png` | Логи після `kill <pid>` з повідомленням про *shutting down gracefully* |

Після збереження файлів можна вставити в кореневий `README.md` прев’ю, наприклад:

```markdown
![Health 200](./docs/health-200.png)
```

У кореневому README вже наведено **текстовий** приклад виводу для порівняння зі скриншотами.
